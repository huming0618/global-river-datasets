# GloFAS Historical

| 项 | 内容 |
|---|---|
| **提供方** | Copernicus CEMS |
| **类别** | 模拟 / 再分析流量 |
| **覆盖范围** | global excl. Antarctica |
| **官方链接** | https://ewds.climate.copernicus.eu/datasets/cems-glofas-historical |
| **许可要点** | Copernicus account required |
| **常见格式** | GRIB2、NetCDF-4 |

## 适用场景

全球格点日流量再分析

## 注意事项

不是实测站数据。GloFAS v5.0 等重大更新会换新再分析，下载时选清版本。
