# HydroRIVERS

| 项 | 内容 |
|---|---|
| **提供方** | WWF / HydroSHEDS |
| **类别** | 河网（矢量线） |
| **覆盖范围** | global |
| **官方链接** | https://www.hydrosheds.org/products/hydrorivers |
| **许可要点** | HydroSHEDS terms; research/education/commercial OK with attribution |
| **常见格式** | File Geodatabase、Shapefile |

## 适用场景

全球一致河网矢量，默认制图与拓扑起点

## 注意事项

中国/亚洲有 Asia、Siberia 分区下载；山区、平原、三角洲等复杂地形区，SRTM 衍生产品精度可能偏低，精细研究建议与 MERIT / OSM 交叉验证。
