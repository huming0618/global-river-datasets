# JRC Global Surface Water

| 项 | 内容 |
|---|---|
| **提供方** | JRC / Copernicus |
| **类别** | 卫星衍生水面 / 河宽 |
| **覆盖范围** | global |
| **官方链接** | https://global-surface-water.appspot.com/download |
| **许可要点** | Copernicus free with citation |
| **常见格式** | tiles、GEE、WMS |

## 适用场景

Landsat衍生全球水面Occurrence等

## 注意事项

长期 Occurrence 等已到约 2024；Seasonality/月年历史等需按官方说明合并版本。Landsat Collection 1/2 拼接存在亚像元至约一像元配准差。
