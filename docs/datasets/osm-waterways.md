# OpenStreetMap waterways

| 项 | 内容 |
|---|---|
| **提供方** | OSM / Geofabrik |
| **类别** | 河网（矢量线） |
| **覆盖范围** | global uneven |
| **官方链接** | https://download.geofabrik.de/ |
| **许可要点** | ODbL 1.0 |
| **常见格式** | PBF、Shapefile、GeoPackage |

## 适用场景

众包水道，补人工河道与地名

## 注意事项

中国东部人口密集区往往较密，西部与偏远山区可能稀疏或不一致，务必抽样核对。无统一全球拓扑/流量。
