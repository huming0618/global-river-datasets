# SWORD

| 项 | 内容 |
|---|---|
| **提供方** | SWOT science team / UNC |
| **类别** | 河网（矢量线） |
| **覆盖范围** | global wide rivers |
| **官方链接** | http://gaia.geosci.unc.edu/SWORD/ |
| **许可要点** | Often CC BY on Zenodo; check release page |
| **常见格式** | NetCDF、GeoPackage、Shapefile |

## 适用场景

面向 SWOT 的宽河河段/节点框架

## 注意事项

面向较宽河道（大致可被 SWOT/光学宽度产品观测，约 >30 m 量级）。许可以当期 Zenodo/发行页为准。
