# HydroBASINS

| 项 | 内容 |
|---|---|
| **提供方** | HydroSHEDS / WWF |
| **类别** | 流域 / 集水区 |
| **覆盖范围** | global land excl. Antarctica |
| **官方链接** | https://www.hydrosheds.org/products/hydrobasins |
| **许可要点** | HydroSHEDS terms |
| **常见格式** | Shapefile |

## 适用场景

全球嵌套子流域 Pfafstetter 1–12 级

## 注意事项

有 Asia 包；精细小流域或高原内流区建议与 MERIT-Basins 单元流域对比。
